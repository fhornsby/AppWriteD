# Changelog

## 0.1.0

* Initial release: client SDK generated from the Appwrite 2.5.x API specification.
* Every client service (Account, Databases, TablesDB, Storage, Functions, Teams, Avatars, Locale, Messaging, GraphQL and more) with typed models and enums.
* Persistent session cookies, OAuth2 sign-in through the system browser, chunked file uploads with progress.
* Realtime subscriptions over WebSocket, with no dependency beyond libcurl.
* `Future`/dispatcher helpers for calling the API from a UI thread without blocking it.
